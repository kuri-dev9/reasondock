# 4. 인터페이스 정의

## 4.1 인터페이스 유형 개요

| 유형 | 프로토콜 | 용도 | 관련 모듈 |
|------|----------|------|-----------|
| REST API | HTTP/JSON | 대화/첨부/지식/RCA CRUD, 모델 조회 | conversations, attachments, knowledge, models, rca |
| SSE 스트리밍 | HTTP/SSE | 채팅 응답 토큰 스트리밍 | chat |
| 외부 HTTP | HTTP/JSON | Ollama LLM API 호출 | services/llm.py, knowledge.py, models.py |
| 파일 업로드 | HTTP/multipart | 첨부파일, 지식문서, xDR 파일 업로드 | attachments, knowledge, rca |
| 파일 다운로드 | HTTP/octet-stream | 대화 내보내기 | conversations |

## 4.2 REST API — 대화 관리 (`/api/conversations`)

| Method | Path | 설명 | 요청 | 응답 |
|--------|------|------|------|------|
| GET | `/api/conversations` | 대화 목록 조회 (updated_at DESC) | - | `ConversationResponse[]` |
| GET | `/api/conversations/search?q={keyword}` | 대화/메시지 검색 (LIKE) | Query: `q` (min 1자) | `SearchResult[]` (최대 50건) |
| POST | `/api/conversations` | 대화 생성 | `ConversationCreate` | `ConversationResponse` (201) |
| GET | `/api/conversations/{id}` | 대화 상세 (메시지 포함) | Path: `id` | `ConversationDetailResponse` |
| PATCH | `/api/conversations/{id}` | 대화 수정 | `ConversationUpdate` | `ConversationResponse` |
| DELETE | `/api/conversations/{id}` | 대화 삭제 (CASCADE) | Path: `id` | 204 No Content |
| GET | `/api/conversations/{id}/export?format={fmt}` | 대화 내보내기 | Query: `format` (json\|markdown) | 파일 다운로드 |
| POST | `/api/conversations/import` | 대화 가져오기 | `ConversationImport` | `ConversationResponse` (201) |

## 4.3 SSE 스트리밍 — 채팅 (`/api/conversations/{id}/chat`)

| Method | Path | 설명 |
|--------|------|------|
| POST | `/api/conversations/{id}/chat` | SSE 스트리밍 채팅 |

### 요청

```json
{
  "message": "사용자 메시지 내용"
}
```

### SSE 이벤트 형식

모든 이벤트는 `data: {JSON}\n\n` 형식으로 전송됩니다.

| 이벤트 타입 | JSON 구조 | 설명 |
|-------------|-----------|------|
| thinking | `{"thinking": "토큰"}` | 모델 사고 과정 토큰 (thinking 모델만) |
| token | `{"token": "토큰"}` | 응답 본문 토큰 |
| done | `{"done": true, "title": "제목", "references": [...]}` | 응답 완료 (title은 첫 메시지만) |
| error | `{"error": "에러 메시지"}` | 오류 발생 |

### references 배열 구조

```json
[
  {
    "filename": "문서명.pdf",
    "score": 0.875,
    "matched_summary": true
  }
]
```

## 4.5 REST API — 지식 저장소 (`/api/knowledge`)

| Method | Path | 설명 | 요청 | 응답 |
|--------|------|------|------|------|
| GET | `/api/knowledge` | 지식 문서 목록 | - | 문서 배열 |
| POST | `/api/knowledge/upload` | 지식 문서 업로드 (최대 20MB) | multipart/form-data (`file`) | 문서 정보 JSON |
| GET | `/api/knowledge/{id}/status` | 문서 처리 상태 조회 | Path: `id` | 상태 JSON |
| DELETE | `/api/knowledge/{id}` | 지식 문서 삭제 | Path: `id` | 204 No Content |

### 문서 상태

| status | 설명 |
|--------|------|
| `processing` | 텍스트 추출/요약 생성/청크 분할 진행 중 |
| `ready` | 처리 완료, 검색 가능 |
| `error` | 처리 실패 (error_message에 상세 내용) |

## 4.6 REST API — RCA 분석 (`/api/rca`)

| Method | Path | 설명 | 요청 | 응답 |
|--------|------|------|------|------|
| POST | `/api/rca/jobs` | xDR 파일 업로드 + RCA 분석 실행 | multipart/form-data (`conversation_id`, `use_uce`, `file`) | RcaAnalyzeResponse JSON (200) |
| GET | `/api/rca/jobs` | RCA Job 목록 | - | RcaJob 배열 |
| GET | `/api/rca/jobs/{job_id}` | RCA Job 상태 조회 | Path: `job_id` | RcaJob JSON |
| GET | `/api/rca/jobs/{job_id}/stream` | RCA 진행 SSE 스트림 | Path: `job_id` | text/event-stream |
| GET | `/api/rca/results/{job_id}` | RCA 결과 JSON 조회 | Path: `job_id` | summary_json |

### RcaJob 응답

```json
{
  "id": 1,
  "conversation_id": 3,
  "filename": "LTE-CALL-KPI_R1_20260520_0900.dat",
  "file_size": 524288000,
  "status": "done",
  "progress": 100,
  "current_step": "done",
  "total_records": 120430,
  "parsed_records": 119872,
  "error_message": null,
  "result_path": "/app/rca_results/rca_job_1.json",
  "created_at": "2026-05-20T09:00:00",
  "updated_at": "2026-05-20T09:03:21"
}
```

### RcaJob status 값

| status | 설명 |
|--------|------|
| `queued` | 업로드 완료 후 백그라운드 실행 대기 |
| `parsing` | xDR 파싱 중 |
| `aggregating` | 집계 및 Rule 기반 RCA summary 생성 중 |
| `llm` | LLM RCA 리포트 생성 중 |
| `done` | 분석 완료 |
| `error` | 실패 (error_message에 상세 내용) |

### RCA 진행 SSE 이벤트

```json
{
  "job_id": 1,
  "step": "llm_token",
  "progress": 90,
  "token": "분석 기간 동안..."
}
```

`step` 값은 `queued`, `parsing`, `aggregating`, `summary_token`, `summary_done`, `llm_prepare`, `llm`, `llm_token`, `done`, `error`를 사용합니다. `done` 이벤트에는 생성된 assistant message가 포함됩니다.

### RCA 결과 응답 (`summary_json`)

`GET /api/rca/results/{job_id}`는 `RcaResult` 래퍼 객체가 아니라 DB에 저장된 `summary_json` 본문을 그대로 반환합니다.

```json
{
  "job_id": 1,
  "conversation_id": 3,
  "file_info": {
    "filename": "LTE-CALL-KPI_R1_20260520_0900.dat"
  },
  "overall": {
    "total_records": 120430,
    "fail_rate": 0.043
  },
  "rca_candidates": [],
  "llm_response": "분석 기간 동안 전체 120,430건 중 4.3%의 호 처리 실패가 관찰되었습니다..."
}
```

## 4.9 외부 연동 — Ollama API

채팅과 RCA는 `services/llm.py`를 경유합니다. 지식 문서 요약과 모델 목록 조회는 현재 라우터가 Ollama를 직접 호출합니다.

| Ollama API | 호출 경로 | Method | 용도 | Timeout |
|------------|-----------|--------|------|---------|
| `/api/chat` | llm.py → chat.py | POST (stream) | 대화 스트리밍 응답 | 300s |
| `/api/generate` | llm.py → chat.py | POST | 자동 제목 생성 | 60s |
| `/api/generate` | knowledge.py | POST | 문서 요약 생성 | 120s |
| `/api/chat` | llm.py → rca.py | POST (stream) | RCA 결과 자연어 설명 생성 | 1800s |
| `/api/tags` | models.py | GET | 모델 목록 조회 | 10s |
